# rust-solana-playground

A **hands-on learning lab** where I practice and experiment with **Rust**, **Solana**, and **Anchor** every day.

This is not a production repository.

This is where I:

- break things  
- fix them  
- understand **why they broke**

> This repository exists purely for **learning and experimentation**.  
> Production-ready systems live in separate repositories.

---

## What’s Inside

### Rust Fundamentals
- Ownership and Borrowing  
- Lifetimes  
- Traits and Generics  
- Result and Error Handling  
- Memory-safe patterns  

---

### Solana Core Concepts
- Solana Account Model  
- Program Derived Accounts (PDAs)  
- Instruction design  
- Authority and signer validation  
- Rent and lamport mechanics  

---

### Anchor Patterns
- Account constraints  
- Secure initialization  
- Custom error handling  
- Best-practice account validation  

---

Everything in this repository is written, tested, broken, and rewritten by me while learning low-level **Solana program architecture**.
